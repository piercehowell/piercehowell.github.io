# Instructions

## Local Testing
- `rbenv` is used as the ruby version manager.
- Check that your ruby version is meets the standards for the github-pages version (found in the Gemfile). I get this to work successfully with Ruby version 3.1.4. To check the version running, run `rbenv versions`
- To install the ruby packages for the project, run `bundle install`
- To run the webserver locally, run `bundle exec jekyll serve`.

## Editing Notes
- If you want to make some custom styling changes, go ahead and use `assets/main.css`.
